# 📊 Regional Digital Payment Dynamics & Demographic Analysis

## Overview

This project delivers an end-to-end analysis of regional **digital transaction trends, population dynamics, and device usage** across Indian states and districts using Python. 
By combining time-series transaction records with demographic statistics, the study provides actionable insights into how user behavior, geographic location, and population metrics shape digital payment adoption.

---

## Key Technical Workflows
* **Data Merging & Aggregations:** Combined demographic metrics with time-series payment data on shared geographic keys using `pandas`, isolating quarterly snapshots to prevent cumulative data inflation.
* **Exploratory Data Analysis (EDA):** Calculated key metrics, including average transaction amounts per user and district-level population densities.
* **Correlation Analysis:** Analyzed the relationship between demographic indicators—such as population density—and quarterly transaction volume across distinct geographic regions.
* **Data Visualization:** Built linear and categorical bar charts using `Matplotlib` and `Seaborn`, adjusting axis scales to accurately plot data across varying volume ranges.
